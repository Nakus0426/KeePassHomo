# 密码强度计算器说明

## 目标与适用范围

`PasswordStrengthCalculator` 用于对用户正在输入的任意非空密码做轻量、同步、可解释的强度评估。结果由 `StrengthLevel` 表示：
`Invalid`、`VeryWeak`、`Weak`、`Medium`、`Strong`、`VeryStrong`，对应数值 0–5。

空字符串返回 `Invalid`。其他非空 `string`（包含中文和其他 Unicode 字符）均可评估。计算器不访问网络、不保存密码、不引入第三方依赖。

## 设计依据

成熟密码管理器通常综合考虑长度、字符空间和可猜测模式，而不是只统计“用了几类字符”。本项目采用这一通用思路的轻量版本：

- 长度提供主要安全增益。
- 大小写、数字、特殊字符和非 ASCII 字符补充字符空间。
- 常见词、数字后缀、键盘序列、连续字符和重复片段降低评分。
- 明显的整串重复模式直接判为很弱，避免超长重复字符串被长度抬高。

该设计借鉴成熟密码管理器的评估原则，不复制任何第三方实现、词典或源码。

## 评分规则

### 基础分

| 密码长度  | 分数 |
|-------|---:|
| 1–4   |  0 |
| 5–7   | 10 |
| 8–10  | 20 |
| 11–14 | 35 |
| 15–19 | 50 |
| ≥20   | 60 |

### 字符类型加分

- 小写字母：+10
- 大写字母：+10
- 数字：+10
- 特殊字符：+10
- 非 ASCII 字符：额外 +5

纯数字或纯字母密码额外扣 20 分。

### 弱模式扣分

- 小型中英文常见弱密码词表命中：-35
- 弱密码词后带 1–4 位数字：再扣 10
- 字母、数字或常见键盘序列（连续片段长度至少 3）：-25
- 连续重复字符或短片段重复：-25
- 整串由单字符重复，或由长度 1–3 的片段循环组成：直接 `VeryWeak`

弱词匹配忽略 ASCII 大小写，覆盖 `password`、`passw0rd`、`admin`、`qwerty`、`welcome`、`letmein`、`123456`、`111111`、`密码`、
`管理员`、`欢迎`、`测试` 等代表性模式。

### 等级映射

|   最终分数 | 等级           | UI 描述 |
|-------:|--------------|-------|
|   0–19 | `VeryWeak`   | 很弱    |
|  20–39 | `Weak`       | 较弱    |
|  40–59 | `Medium`     | 一般    |
|  60–79 | `Strong`     | 较强    |
| 80–100 | `VeryStrong` | 很强    |

长度还提供等级上限：1–4 位最多很弱，5–7 位最多较弱，8–9 位最多一般。这样 `aB3!` 不会因字符类型多而被评为高强度。

## 示例

| 输入                 | 主要原因               | 结果                  |
|--------------------|--------------------|---------------------|
| 空字符串               | 无有效输入              | `Invalid`，圆点全灰、隐藏描述 |
| `123456`           | 纯数字、常见弱词、连续序列      | 很弱                  |
| `Password1`        | 常见词及数字后缀           | 较弱或一般，受长度和扣分共同限制    |
| `aaaaaa`           | 整串单字符重复            | 很弱                  |
| `abcabc`           | 整串短片段循环            | 很弱                  |
| `aB3!`             | 长度过短               | 很弱                  |
| `River9!Maple`     | 长度较长、大小写/数字/特殊字符混合 | 一般至较强               |
| `T7!qL2#vN8@pR4$z` | 长度充足、字符类型丰富、无明显模式  | 较强或很强               |

## UI 使用

```ts
PasswordStrengthIndicator({
  password: password,
})
```

组件只负责展示：五个 14vp 圆点、4vp 点间距、三段之间 8vp 间距。未点亮圆点使用 `sys.color.comp_background_secondary`；很弱/较弱使用
`sys.color.alert`，一般使用 `sys.color.warning`，较强/很强使用 `sys.color.confirm`。空密码或 `Invalid` 不显示描述。

## 边界与维护

- 算法是启发式指标，不等价于泄露库查询、密码破解时间或正式安全证明。
- 词表保持小型，新增模式时应补充示例并检查误报。
- 修改阈值后需同步更新本文档和人工验收场景。
