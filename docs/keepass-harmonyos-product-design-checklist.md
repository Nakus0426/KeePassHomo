# KeePass HarmonyOS 移动端功能设计清单

> 用途：作为产品范围、页面设计和 Google Stitch 出图输入的统一基线。  
> 目标设备：HarmonyOS 手机、平板。  
> 目标用户：个人用户。  
> 数据模型：本地优先的 KDBX 文件，不提供产品账号体系。  
> 文档版本：v1.0，2026-08-18。

## 1. 优先级与产品边界

### 1.1 优先级

- `[P0]` 首版必须存在，缺失会导致核心流程不可用。
- `[P1]` 首版完成可行性验证和设计占位，验证通过后进入实现。
- `[P2]` 后续版本候选，不应出现在 P0 主流程中。

### 1.2 产品原则

- [ ] `[P0]` 用户无需注册、登录产品账号或购买订阅即可使用。
- [ ] `[P0]` KDBX 文件是数据真源，应用不得建立不可导出的私有密码库格式。
- [ ] `[P0]` 默认离线可用；仅 WebDAV 同步和用户主动开启的泄露检测需要联网。
- [ ] `[P0]` 所有高风险操作必须显式反馈，不允许静默覆盖、静默上传或静默删除。
- [ ] `[P0]` 敏感值默认遮挡；截图、最近任务预览、剪贴板和后台切换按安全优先处理。
- [ ] `[P0]` 手机和平板共享信息架构，平板利用额外空间展示列表与详情，不增加独有功能。
- [ ] `[P0]` 参考 1Password 的完整性和操作效率，不复制其品牌、插画、配色或页面构图。

### 1.3 明确不做

- [ ] `[P1]` 系统级自动填充只做能力验证，不承诺 P0 可接管系统密码保险箱。
- [ ] `[P2]` Passkey 保存与填充。
- [ ] `[P2]` Dropbox、OneDrive、Google Drive、SFTP 等额外同步源。
- [ ] `[P2]` KeePass 1.x `.kdb` 文件导入。
- [ ] `[P2]` 家庭共享、团队空间、成员权限、审计后台。
- [ ] `[P2]` 产品账号、订阅、云端托管密码库。

## 2. 全局信息架构

### 2.1 主导航

| 入口 | 优先级 | 手机 | 平板 | 默认落点 |
| --- | --- | --- | --- | --- |
| 保险库 | P0 | 底部悬浮胶囊导航 | 左侧悬浮导航栏 | 最近使用的分组或全部条目 |
| 安全中心 | P0 | 底部悬浮胶囊导航 | 左侧悬浮导航栏 | 安全概览 |
| 生成器 | P0 | 底部悬浮胶囊导航 | 左侧悬浮导航栏 | 随机密码模式 |
| 设置 | P0 | 底部悬浮胶囊导航 | 左侧悬浮导航栏 | 设置首页 |
| 搜索 | P0 | 顶部悬浮搜索胶囊 | 条目列表顶部悬浮搜索栏 | 全库搜索 |
| 锁定 | P0 | 顶部光感标题栏锁图标 | 侧栏底部悬浮锁定控件 | 锁定页 |

### 2.2 响应式规则

- [ ] `[P0]` 手机竖屏使用单栏导航；核心条目详情进入独立页面，短时上下文操作优先使用半模态或浮层。
- [ ] `[P0]` 手机横屏保持单栏或紧凑双栏，不压缩表单字段到不可读宽度。
- [ ] `[P0]` 平板保险库使用“导航栏 + 条目列表 + 条目详情”三段式布局。
- [ ] `[P0]` 平板安全中心、生成器、设置使用“导航栏 + 内容”双栏布局。
- [ ] `[P0]` 平板未选择条目时显示中性占位，不自动展示敏感条目。
- [ ] `[P0]` 所有固定导航、图标按钮、风险计数和 TOTP 倒计时使用稳定尺寸，动态内容不得造成布局跳动。
- [ ] `[P0]` 文字支持系统字体缩放；较长库名、标签、网址允许换行或省略并提供完整查看入口。

### 2.3 全局视觉与交互约束

- [ ] `[P0]` 采用 HarmonyOS 最新“沉浸光感（Immersive Light）”空间化设计语言，以光学扩散、动态透光、折射、漫反射和柔和光晕建立 Z 轴层次。
- [ ] `[P0]` 目标体感可接近 iOS 26 的悬浮透明层与流动光效，但组件结构、材质档位、色彩 Token、交互反馈和无障碍规则必须遵循 HarmonyOS，不复制 iOS 控件。
- [ ] `[P0]` 大量使用悬浮交互组件：底部胶囊导航、顶部标题栏、搜索胶囊、筛选胶囊、悬浮主按钮、可折叠 MiniBar、条目操作坞、上下文菜单和半模态。
- [ ] `[P0]` 内容在顶部、底部悬浮组件下自然延伸；使用渐变模糊和渐变颜色蒙层保障文字可读，释放内容屏占比。
- [ ] `[P0]` 光感材质必须服务于导航和操作层级；长列表、密集表单、密码字段和风险说明保持稳定、清晰的内容承载面，禁止无意义地全部透明化。
- [ ] `[P0]` 允许光学渐变、材质流光与渐变模糊；仍禁止营销式大面积彩色渐变背景、装饰色球和无功能光斑。
- [ ] `[P0]` 悬浮组件使用系统圆角或全圆角胶囊；内容卡片使用系统圆角 Token；禁止玻璃卡片内再嵌套玻璃卡片。
- [ ] `[P0]` 常见操作使用系统图标：搜索、复制、显示、隐藏、编辑、删除、刷新、锁定、更多。
- [ ] `[P0]` 图标按钮提供无障碍名称和触摸提示；文本命令只用于“保存”“取消”“继续”等明确动作。
- [ ] `[P0]` 按压时使用触点光源扩散、弹性缩放和轻触觉反馈；滚动时标题栏与导航栏透明度、模糊度平滑变化，禁止夸张弹跳。
- [ ] `[P0]` 材质前景启用智能反色或等效对比保护；任何背景下文本、图标、风险状态均须清晰可读。
- [ ] `[P0]` 同时设计浅色、深色；跟随用户系统光感强度和设备性能自动降级，不要求用户理解材质技术参数。
- [ ] `[P0]` 示例密码、TOTP 密钥、WebDAV 密码始终使用遮挡值，不在设计稿中出现可用秘密。

### 2.4 沉浸光感材质层级

| 场景 | 优先级 | 官方材质档位 | 设计要求 |
| --- | --- | --- | --- |
| 顶部悬浮标题栏、顶部搜索栏 | P0 | `ULTRA_THIN` | 内容延伸至其下；滚动时从透明平滑过渡到渐变模糊 |
| 底部悬浮导航、底部操作坞、MiniBar | P0 | `THIN` | 使用底部渐变颜色蒙层；与安全区保持悬浮间距 |
| 任意位置临时弹出的菜单、提示、筛选面板 | P0 | `THICK` | 提升复杂背景上的可读性；关闭后不保留光效 |
| 半模态、操作面板、弹出框 | P0 | `ULTRA_THICK` | 承载较多信息；保持稳定对比度与明确的遮罩层级 |
| 普通内容列表、表单正文 | P0 | 无常驻强材质 | 使用实色或低干扰容器 Token，避免信息被背景穿透干扰 |

- [ ] `[P0]` 默认采用系统 `ADAPTIVE` 材质级别，让系统根据设备性能选择表现；设计稿以“均衡”强度为基准。
- [ ] `[P0]` 强档可增加折射、粒子流转和空间光效；均衡档保持通透与对比；弱档减少光彩并提高对比度。
- [ ] `[P0]` 高级材质不可用、低性能、节能或减少透明度场景下，降级为系统模糊或不透明容器，布局与功能不得变化。
- [ ] `[P0]` 同屏悬浮层级保持克制：常驻主层不超过顶部栏、底部栏和一个上下文操作层，避免多重玻璃叠加。

### 2.5 HarmonyOS 色彩 Token

- [ ] `[P0]` 使用系统 Token 管理颜色，不按页面散落硬编码色值；浅色与深色使用同名 Token，由系统映射不同数值。
- [ ] `[P0]` 品牌与高亮采用系统“宇宙蓝”：`brand` 浅色 `#0A59F7`、深色 `#317AF7`。
- [ ] `[P0]` 基础背景采用“雪域灰”与系统背景 Token：`background_primary`、`background_secondary`、`background_tertiary`；背景层必须使用不透明色。
- [ ] `[P0]` 确认成功使用 `confirm`：浅色 `#64BB5C`、深色 `#5BA854`；绿色不再作为全局主色。
- [ ] `[P0]` 一级警示使用 `warning`：浅色 `#E84026`、深色 `#D94838`；二级提醒使用 `alert`：浅色 `#ED6F21`、深色 `#DB6B42`。
- [ ] `[P0]` 文本和图标按 `primary / secondary / tertiary / fourth` 四级语义 Token 分层；品牌容器上的内容使用 `onPrimary` 反色 Token。
- [ ] `[P0]` 控件容器使用 `comp_background_primary / secondary / tertiary / emphasize`；悬停、按压、获焦、选中分别使用 `interactive_hover / pressed / focus / select`。
- [ ] `[P0]` 常规文本与背景至少满足 3:1 对比度；密码、风险说明、确认动作按更高可读性目标设计，不以透明度牺牲辨识度。
- [ ] `[P0]` 风险不只靠颜色表达；同时使用 Symbol、文本、严重度和位置层级。

### 2.6 页面、半模态与浮层规则

| 容器 | 优先级 | 适用内容 | 本产品典型场景 |
| --- | --- | --- | --- |
| 独立页面 | P0 | 高频主任务、长列表、长表单、需要稳定返回栈的内容 | 保险库、条目详情与编辑、安全中心、生成器、同步中心、设置首页 |
| 半模态面板 | P0 | 从当前上下文发起、完成后返回原位置、信息量中等的任务 | 数据源快捷配置、模板选择、生物认证、旧库升级、TOTP 设置、移动目标、冲突处理、敏感设置、再认证 |
| 临时浮层/菜单 | P0 | 少量选项、筛选、排序、更多操作、无需长文本 | 排序、筛选、标签选择、条目更多菜单、同步状态菜单 |
| 确认弹窗 | P0 | 不可逆或高风险的二元确认、阻断性错误 | 永久删除、清空回收站、放弃未保存内容、证书错误 |

- [ ] `[P0]` 不为每个操作创建新页面；能在当前上下文内完成且完成后无需保留独立返回节点的任务，优先使用半模态。
- [ ] `[P0]` 半模态使用 `ULTRA_THICK` 材质；背景内容保留空间关系但降低干扰，敏感值继续遮挡。
- [ ] `[P0]` 手机半模态从底部展开，使用内容自适应、中等高度和近全高挡位；长内容在面板内部滚动，主操作固定在面板底部。实现时对应 ArkUI `bindSheet` 的高度与 `detents` 能力。
- [ ] `[P0]` 平板半模态使用居中或右侧定宽面板，不无意义铺满屏幕；背景列表与当前选中项保持可辨识关系。
- [ ] `[P0]` 半模态支持下滑、关闭按钮和系统返回；存在未保存内容、高风险确认或进行中任务时，点击遮罩不得直接丢弃状态。
- [ ] `[P0]` 同一时刻只显示一个半模态；下一层简单选项使用面板内菜单，不连续堆叠多层半模态。
- [ ] `[P0]` 浮层只承载少量选项；内容超过一屏、需要验证或包含危险操作时升级为半模态。
- [ ] `[P0]` 关闭半模态后恢复原页面滚动位置、筛选条件、选中项和键盘焦点。

## 3. 页面清单 A：引导、数据源与解锁

### A01 启动安全遮罩 `[P0]`

**目标：** 冷启动、恢复前台、解密过程中不泄露上次页面。

- [ ] `[P0]` 展示应用图标、小型进度指示、当前阶段“正在准备保险库”。
- [ ] `[P0]` 启动遮罩使用低干扰光感呼吸效果；不得透出上次条目详情或用高亮流光暗示真实密码内容。
- [ ] `[P0]` 不展示条目名、库名、最近搜索或同步路径。
- [ ] `[P0]` 超过合理等待时间后显示“重试”和“查看错误详情”。
- [ ] `[P0]` 恢复前台时先显示遮罩，再判断是否仍在解锁有效期内。

**状态：** `loading`、`storageUnavailable`、`fatalError`。

### A02 首次使用与数据源选择 `[P0]`

**目标：** 让用户创建新库、打开本地库或连接 WebDAV。

- [ ] `[P0]` 主操作：创建新保险库。
- [ ] `[P0]` 次操作：打开本地 KDBX。
- [ ] `[P0]` 次操作：连接 WebDAV。
- [ ] `[P0]` 三个来源操作使用悬浮光感按钮组；主操作使用 `brand` 强调，次操作使用通透材质容器。
- [ ] `[P0]` 简短说明“数据保存在你的 KDBX 文件中，本应用不要求账号”。
- [ ] `[P0]` 文件权限被拒绝时解释用途，并提供重新选择入口。
- [ ] `[P0]` 不出现免费试用、注册、登录或订阅文案。

**状态：** `default`、`filePermissionDenied`、`noFileProvider`。

### A03 创建新保险库 `[P0]`

**目标：** 创建 KDBX 4.x 文件并设置复合凭据。

- [ ] `[P0]` 输入库名；默认建议“个人保险库”。
- [ ] `[P0]` 选择保存位置；显示本地路径提供方，不显示完整隐私路径到最近任务预览。
- [ ] `[P0]` 输入并确认主密码；提供实时强度、长度与不匹配反馈。
- [ ] `[P0]` 可选添加密钥文件；明确“遗失密钥文件将无法打开保险库”。
- [ ] `[P0]` 支持生成主密码建议，但生成后要求用户确认已妥善保存。
- [ ] `[P0]` 创建前展示摘要：格式、位置、是否使用密钥文件。
- [ ] `[P0]` 写入失败时保留表单并允许更换位置或重试。

**状态：** `editing`、`weakPassword`、`passwordMismatch`、`pathUnavailable`、`writeFailed`、`success`。

### A04 打开本地 KDBX `[P0]`

**目标：** 通过系统文件选择器打开现有库。

- [ ] `[P0]` 过滤并优先显示 `.kdbx` 文件。
- [ ] `[P0]` 选择后展示文件名、格式版本、大小、最后修改时间。
- [ ] `[P0]` 识别 KDBX 4.x、KDBX 3.1、损坏文件、不支持格式。
- [ ] `[P0]` 文件不可写时允许只读打开，并明确只读状态。
- [ ] `[P0]` 文件移动或权限失效时提供重新定位入口。

**状态：** `selecting`、`valid`、`readOnly`、`permissionDenied`、`missing`、`corrupt`、`unsupported`。

### A05 连接 WebDAV `[P0]`

**目标：** 配置远程 KDBX 文件并验证连接。

**呈现：** 从数据源选择页打开全高半模态；连接成功后关闭面板并进入解锁页。

- [ ] `[P0]` 字段：服务器地址、用户名、密码、远程文件路径。
- [ ] `[P0]` 密码默认遮挡；提供显示按钮，显示 10 秒后自动隐藏。
- [ ] `[P0]` 提供“测试连接”；显示 DNS、超时、认证、证书、404、权限错误的可行动说明。
- [ ] `[P0]` TLS 证书异常不得提供默认忽略；仅展示证书摘要与取消入口。
- [ ] `[P0]` 连接成功后展示远程文件元数据，再进入解锁。
- [ ] `[P0]` 支持“下载副本后离线打开”，但明确后续同步状态。

**状态：** `editing`、`testing`、`success`、`offline`、`authFailed`、`certificateError`、`notFound`、`readOnly`。

### A06 解锁保险库 `[P0]`

**目标：** 使用主密码和可选密钥文件解密 KDBX。

- [ ] `[P0]` 展示库名、来源类型、本地或 WebDAV 状态，不展示内部条目。
- [ ] `[P0]` 主密码输入支持显示 10 秒；默认关闭显示。
- [ ] `[P0]` 需要密钥文件时显示已选文件名和重新选择入口。
- [ ] `[P0]` 支持系统密码键盘、提交加载态、防重复提交。
- [ ] `[P0]` 错误凭据只提示“凭据不正确或文件无法解密”，不推断具体错误字段。
- [ ] `[P0]` 连续失败时采用逐步延迟，不清空用户已选密钥文件。
- [ ] `[P0]` 可切换最近保险库或返回数据源选择。

**状态：** `locked`、`unlocking`、`wrongCredential`、`keyFileMissing`、`vaultChanged`、`corrupt`。

### A07 生物快速解锁设置 `[P0]`

**目标：** 首次成功解锁后允许启用系统认证。

**呈现：** 解锁成功后的半模态；用户跳过后直接进入保险库，不新增空白过渡页。

- [ ] `[P0]` 解释生物认证只保护本机保存的快速解锁材料，不替代 KDBX 主密码。
- [ ] `[P0]` 调用系统用户认证控件，不自行绘制指纹或人脸采集界面。
- [ ] `[P0]` 设备未录入生物特征时提供跳过与前往系统设置入口。
- [ ] `[P0]` 生物认证失败、取消、锁定时回退主密码。
- [ ] `[P0]` 启用成功后允许选择自动锁定时长，默认 5 分钟。

**状态：** `available`、`authenticating`、`enabled`、`cancelled`、`notEnrolled`、`lockedOut`。

### A08 KDBX 3.1 升级 `[P0]`

**目标：** 安全地将旧库升级为 KDBX 4.x。

**呈现：** `ULTRA_THICK` 阻断式半模态；保留文件摘要背景，不创建独立升级页面。

- [ ] `[P0]` 说明升级原因、目标格式、兼容性影响。
- [ ] `[P0]` 主操作“创建备份并升级”；次操作“暂时只读打开”；取消返回。
- [ ] `[P0]` 展示备份文件名和保存位置。
- [ ] `[P0]` 备份创建失败时禁止继续升级。

5. 表单状态：默认、聚焦、已填写、校验错误、保存中、保存失败、未保存确认和成功返回。
6. 敏感值状态：默认遮挡、临时显示、10 秒自动遮挡、切后台立即遮挡、复制倒计时和再次认证失败。

1. 首次使用：A01 → A02 → A03 或 A04 或 A05 → A06 → 必要时 A08 → A07 → B01。

5. 泄露检测：C01 → C04 → 启用 → 检测中 → 结果；离线时保留本地检测结果。

8. 修改库凭据：D05 → C07-B 再次认证 → D05-A → 自动备份 → 保存结果 → 返回 D05。
9. 自动填充验证：D00 → D07 → D07-A → 系统配置或测试表单 → 成功、失败或安全复制备选。
10. 全局锁定：任意解锁页面 → 自动锁定或手动锁定 → A01 安全遮罩 → A06；不得经过包含敏感内容的过渡画面。
