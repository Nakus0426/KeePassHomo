# 条目预览态 — UI/UX 设计需求说明书

> 交给 UI/UX 设计工具（设计稿生成）的**功能需求提示词**。
> 只描述功能、信息与状态规则，**不描述布局、栅格、层级堆叠、间距、圆角、颜色、字体、图标选型、动效曲线与控件形态**。
> 设计者据此自由发挥视觉与布局；实现方按本文件核对功能完整性。
> 本文件只覆盖预览态，不含编辑态。

## 0. 背景与本次变更范围

KeePass 类密码管理应用（HarmonyOS，Phone 与 Tablet）。

现状：条目详情是一个独立路由页（`EntryDetailPage`），只读展示；编辑是盖在其上的半模态。

目标形态：

- 点击列表中的条目，直接打开**条目半模态**，呈现**预览态**。
- **独立的条目详情路由页被删除**，条目的查看全部在这个半模态内完成。
- 同一半模态内还有编辑形态，可双向切换；编辑形态不在本文件范围内。
- 半模态是承载预览态的容器，本文件包含与预览态直接相关的容器行为。

## 1. 产品定位

条目半模态窗口的默认形态。核心目标是以最少操作完成「看 → 取值（复制、跳转）」，
而不是把条目做成一张只读表单。

## 2. 用户场景

1. 快速取值：查到条目后取密码或用户名，转到外部应用粘贴。
2. 核对信息：确认用户名、网址、备注与当前使用场景是否一致。
3. 触发外部动作：打开网址、发邮件、拨号、查地址地图。
4. 状态管理：加入收藏；归档不再使用的条目。
5. 转入修改：发现信息过期，切换到编辑形态。

## 3. 信息层级

- 主信息：条目标题、分组路径、头像
- 凭据：用户名、密码
- 联系与跳转：网址、备注
- 分类：标签
- 扩展：自定义字段集合，按字段类型区分可执行动作
- 状态：收藏标记、归档标记、已复制反馈与剪贴板清空倒计时、密码可见剩余时间

## 4. 功能需求

### FR-1 打开与关闭

- FR-1.1 在条目列表点击条目，打开预览半模态并加载该条目。
- FR-1.2 半模态支持手势拖拽收起；收起不改变任何数据。
- FR-1.3 保险库在预览期间被锁定，或因闲置、退到后台而超时锁定，半模态自动关闭。
- FR-1.4 预览期间的用户操作计入保险库闲置计时，视为活动。
- FR-1.5 容器在预览态的开合状态，不因切换到编辑形态而改变（窗口本身保持打开）。

### FR-2 字段展示

- FR-2.1 固定字段：标题、用户名、密码、网址、备注。
- FR-2.2 自定义字段：排除固定字段名后按原有顺序展示，保留字段名与值。
- FR-2.3 值为空的字段不展示，不出现「未填写」类占位。
- FR-2.4 长文本（备注、长值自定义字段）默认展示摘要，支持展开与收起。
- FR-2.5 标签以集合形式展示；无标签时该区域不出现。
- FR-2.6 每个字段保留其类型（文本、密码、网址、邮箱、电话、地址），类型决定可用动作。
- FR-2.7 敏感类型字段值不得出现在剪贴板以外的日志、截图或外部跳转中。

### FR-3 取值动作

- FR-3.1 非密码字段提供复制动作。
- FR-3.2 密码字段提供显示与隐藏切换，默认隐藏。
- FR-3.3 密码显示后经过固定秒数自动回到隐藏；计时期间再次点击只切换显示与隐藏，不重置计时。
- FR-3.4 复制成功后给出「已复制」反馈，并展示剪贴板自动清空倒计时。
- FR-3.5 空值不提供复制动作。

### FR-4 字段外部动作（按类型）

- FR-4.1 网址：用系统浏览器打开；缺少协议前缀时自动补全。
- FR-4.2 邮箱：用系统邮件应用打开。
- FR-4.3 电话：用系统拨号打开。
- FR-4.4 地址：用系统地图打开。
- FR-4.5 目标应用缺失或无法处理时给出明确失败提示，不得静默失败。
- FR-4.6 空值不提供外部动作。

### FR-5 条目级动作（标题栏）

- FR-5.1 编辑：切换到同一半模态的编辑形态（编辑形态本身不在本文件范围）。
- FR-5.2 收藏：切换收藏状态，列表即时反映。
- FR-5.3 归档：归档该条目并关闭半模态返回列表，返回后给出归档成功提示。
- FR-5.4 条目已归档时，此动作为「还原」，行为对称：还原后关闭半模态返回列表。
- FR-5.5 保险库只读时，编辑、收藏、归档三个动作均**不出现**，标题栏只保留关闭动作。
- FR-5.6 收藏与归档在执行中不可重复触发。

### FR-6 状态与反馈

- FR-6.1 半模态内可读到条目的收藏状态与归档状态。
- FR-6.2 密码可见倒计时与剪贴板清空倒计时均需要可见。
- FR-6.3 失败提示需带上下文，不使用无信息量的通用文案。
- FR-6.4 应用退到后台或隐私遮挡时，密码可见状态与字段展开状态复位。
- FR-6.5 从编辑形态返回预览态时，预览展示的必须是真实条目数据；密码可见状态回到隐藏，字段展开状态复位。
- FR-6.6 从编辑形态返回预览态时保持原有滚动位置。

## 6. 排除范围

- 不含布局、栅格、层级堆叠、间距、圆角、颜色、字体、图标选型、动效曲线、控件形态选择。

- 不含「新建条目」形态：该形态不经过预览，直接进入编辑形态。
- 不含密码生成器弹出层（仅编辑形态可用）。
- 不含分组管理、搜索、条目列表、回收站、设置等其他模块的交互。
- 不含归档撤销（本期不实现）。
- 不含附件。
