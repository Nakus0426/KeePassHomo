# 密码生成器与强度评估

本文说明当前的密码生成能力、强度评估算法和生成器界面行为。文档以代码为准，涉及的文件：

| 文件                                                                       | 职责                      |
|--------------------------------------------------------------------------|-------------------------|
| `common/src/main/ets/security/PasswordGenerator.ets`                     | 随机密码、易记密码、PIN 三种生成与强度估算 |
| `common/src/main/ets/security/PasswordStrengthCalculator.ets`            | 对用户输入的密码做启发式评分          |
| `products/default/src/main/ets/components/PasswordStrengthIndicator.ets` | 展示评分等级                  |
| `products/default/src/main/ets/viewmodel/GeneratorViewModel.ets`         | 生成器界面状态、参数校验和重新生成       |
| `products/default/src/main/ets/pages/generator/GeneratorComponents.ets`  | 生成器界面与参数控件              |

生成能力的调用位置有三处：底栏「生成器」独立页（`GeneratorPage`）、新建保险库的主密码输入（`CreateVaultPage`）、条目编辑的密码字段（
`EntryEditorView`）。后两处复用同一个 `GeneratorContent` 组件。

## 1. 随机密码

### 1.1 默认参数

| 参数     | 默认值 | 取值范围               | 说明                                     |
|--------|-----|--------------------|----------------------------------------|
| 长度     | 20  | 引擎 8–128，界面滑块 8–20 | 界面当前不暴露 20 以上长度                        |
| 大写字母   | 开启  | 开 / 关              | 字符集 `ABCDEFGHIJKLMNOPQRSTUVWXYZ`       |
| 小写字母   | 开启  | 开 / 关              | 字符集 `abcdefghijklmnopqrstuvwxyz`       |
| 数字     | 开启  | 开 / 关              | 字符集 `0123456789`                       |
| 符号     | 开启  | 开 / 关              | 固定字符集 `!@#$%^&*+-_=?.`（14 个）           |
| 排除相似字符 | 开启  | 开 / 关              | 从大小写字母与数字中移除 `I i l 1 L o 0 O`；符号集不受影响 |
| 最少数字   | 1   | 0–8                | 0 表示不额外保证数字出现次数                        |
| 最少符号   | 1   | 0–8                | 0 表示不额外保证符号出现次数                        |

### 1.2 生成规则

1. 每个启用的字符类型先放入一个必选字符；数字和符号按各自的最少数量继续补足。
2. 剩余位数从启用的字符类型合并后的字符集中逐位随机取字符。
3. 全部字符位使用 Fisher-Yates 洗牌打乱，避免必选字符固定出现在前几位。

字符一律来自 `cryptoFramework.createRandom().generateRandomSync()`，并使用拒绝采样消除模偏差；`generate(length)`
是无参快捷方式，等价于上表默认参数。

### 1.3 参数约束

引擎在生成前校验参数，不满足时抛出异常：

| 条件              | 错误文案                  |
|-----------------|-----------------------|
| 长度不是 8–128 的整数  | 随机密码长度必须为 8 到 128 位整数 |
| 最少数字或最少符号不是非负整数 | 最少数字和符号数量必须为非负整数      |
| 四种字符类型全部关闭      | 请至少启用一种字符类型           |
| 最少数字大于 0 但数字未启用 | 最少数字数量大于 0 时必须启用数字    |
| 最少符号大于 0 但符号未启用 | 最少符号数量大于 0 时必须启用符号    |
| 必选字符数超过总长度      | 密码长度不足以满足当前规则         |
| 安全随机数生成失败       | 安全随机数生成失败：{原因}        |

界面层在 `GeneratorViewModel.randomRuleError()` 中先做同样的规则检查，命中时清空候选、把文案写入 `status` 并以 Toast
提示，因此正常操作不会触发引擎异常。

## 2. 易记密码

| 参数   | 默认值 | 取值范围                |
|------|-----|---------------------|
| 单词数量 | 4   | 3–8（引擎与界面一致）        |
| 分隔符  | `-` | `-`、`.`、`_`、无分隔符    |
| 大小写  | 小写  | 小写 / 首字母大写 / 全大写    |
| 附加数字 | 开启  | 开 / 关，附加一位 0–9 随机数字 |

单词从内置词表随机抽取，词表 128 个短英文单词（自然与日常名词），无重复项。抽取使用与随机密码相同的加密安全随机数。单词数量不是
3–8 的整数时抛出「易记密码的单词数量必须为 3 到 8 个」。

## 3. PIN

| 参数      | 默认值 | 取值范围          |
|---------|-----|---------------|
| 长度      | 6   | 4–12（引擎与界面一致） |
| 避开连续与重复 | 开启  | 开 / 关         |

开启避让时，生成的 PIN 若出现相邻重复数字（如 `11`）或三位连续递增/递减（如 `123`、`987`），会整体重新生成，直到满足条件。长度不是
4–12 的整数时抛出「PIN 长度必须为 4 到 12 位整数」。

## 4. 强度估算（当前未接入界面）

`PasswordGenerator` 另外提供 `estimateRandom`、`estimateMemorable`、`estimatePin`，按字符空间计算估算位数并给出文案：

| 估算位数 | 文案 |
|------|----|
| < 36 | 较弱 |
| < 60 | 一般 |
| < 80 | 较强 |
| ≥ 80 | 很强 |

随机密码按 `长度 × log2(字符集大小)` 估算；易记密码按 `词数 × log2(词表大小)` 加附加数字的 `log2(10)` 估算；PIN 按
`长度 × log2(10)` 估算。

**这三个方法目前没有被任何界面引用**，生成器界面展示的是下一节的启发式评分。保留它们是为了后续接入位数估算，改动界面前不要假设它们已经生效。

## 5. 强度评分算法

`PasswordStrengthCalculator.calculate(password)` 对用户输入的任意密码做同步、无依赖的启发式评分。空字符串返回 `Invalid`
；其余非空字符串（含中文和其他 Unicode 字符）均可评估。计算不访问网络、不保存密码、不引入第三方依赖。

### 5.1 等级

`StrengthLevel` 依次为 `Invalid`、`VeryWeak`、`Weak`、`Medium`、`Strong`、`VeryStrong`，对应数值 0–5。

### 5.2 基础分

| 密码长度  | 分数 |
|-------|---:|
| 1–4   |  0 |
| 5–7   | 10 |
| 8–10  | 20 |
| 11–14 | 35 |
| 15–19 | 50 |
| ≥ 20  | 60 |

### 5.3 加减分

| 条件                          |    分值 |
|-----------------------------|------:|
| 含小写字母                       |   +10 |
| 含大写字母                       |   +10 |
| 含数字                         |   +10 |
| 含特殊字符（非字母数字）                |   +10 |
| 含非 ASCII 字符                 | 额外 +5 |
| 纯数字或纯字母（无特殊字符）              |   −20 |
| 命中内置弱密码词表                   |   −35 |
| 命中弱词且其后恰好跟 1–4 位数字          | 再 −10 |
| 命中键盘序列或三位连续递增/递减            |   −25 |
| 出现连续三位相同字符，或长度 ≥ 6 的整串短片段循环 |   −25 |

弱密码词表覆盖 `password`、`passw0rd`、`admin`、`administrator`、`qwerty`、`qwertyuiop`、`welcome`、`letmein`、`login`、`secret`、
`changeme`、`iloveyou`、`123456`、`12345678`、`123456789`、`111111`、`000000`、`654321`、`密码`、`管理员`、`欢迎`、`测试`。匹配时忽略
ASCII 大小写，但要求整串等于该词，或以该词开头且其后恰好是 1–4 位数字；`Password2024` 这类形式不命中该词表。

键盘序列取 `qwertyuiop`、`asdfghjkl`、`zxcvbnm`、`1234567890` 及其逆序，命中任意连续三位即计分一次。

### 5.4 直接判定与等级上限

- 整串字符完全相同（长度 ≥ 3），或整串由长度 1–3 的片段循环组成（如 `abcabc`、`abab`），直接判定 `VeryWeak`，不再计算分数。
- 最终分数先限制在 0–100，再按 `< 20` 很弱、`< 40` 较弱、`< 60` 一般、`< 80` 较强、`≥ 80` 很强 映射等级。
- 长度另设等级上限：≤ 4 位最多很弱，≤ 7 位最多较弱，≤ 9 位最多一般。因此 `aB3!` 不会因为字符类型齐全而被评为高强度。

## 6. 强度指示器

`PasswordStrengthIndicator({ password })` 只负责展示，不参与生成：

- 左侧固定文案「密码强度」。
- 中间 5 个圆角矩形（高 14vp、圆角 7vp、等宽铺满剩余空间、间距 `sys.float.padding_level4`），点亮数量等于 `StrengthLevel` 数值：
  `Invalid` 全灰，`VeryWeak` 点亮 1 个，`VeryStrong` 点亮 5 个。
- 未点亮颜色 `sys.color.comp_background_secondary`；很弱和较弱使用 `sys.color.alert`，一般使用 `sys.color.warning`，较强和很强使用
  `sys.color.confirm`。
- 右侧显示等级文案；`Invalid` 时不显示描述，仅保留一个零透明度的「很弱」占位以稳定布局。

## 7. 生成器界面行为

- 页签依次为随机密码、易记密码、PIN，页签切换用横向位移加透明度过渡，切换即按新模式的当前参数重新生成。
- 密码卡片显示两行候选；数字着 `sys.color.brand`，符号着 `sys.color.alert`，字母着 `sys.color.font_primary`
  ，并使用等宽密码字体。无候选时显示占位文案。
- 点击密码卡片重新生成；点击标题栏复制动作复制当前候选并提示「已复制」。剪贴板写入与条件清除走应用统一的复制入口。
- 任意参数改动都会立即重新生成；参数非法时清空候选并提示原因，不静默修改用户规则。
- 切后台、锁库或关闭生成器半模态时清除未保存候选；独立生成器页本身不随页面离开清空候选。
- 独立生成器页不提供「保存为新登录条目」；在新建保险库和条目编辑中以半模态打开时，通过填入动作把候选写回当前密码字段。

## 8. 示例

下表为按当前实现实测的评分结果：

| 输入                    | 主要原因              | 结果                    |
|-----------------------|-------------------|-----------------------|
| 空字符串                  | 无有效输入             | `Invalid`，指示器全灰且不显示描述 |
| `123456`              | 纯数字、命中弱词、连续序列     | 很弱                    |
| `Password1`           | 命中弱词并带数字后缀        | 很弱                    |
| `qwerty`              | 命中键盘序列与弱词         | 很弱                    |
| `管理员`                 | 命中中文弱词            | 很弱                    |
| `aaaaaa`              | 整串单字符重复           | 很弱                    |
| `abcabc` / `abab`     | 整串短片段循环           | 很弱                    |
| `aB3!`                | 长度不足，字符类型再多也受限    | 很弱                    |
| `密码abc123`            | 长度不足且有连续字符        | 较弱                    |
| `correcthorsebattery` | 全小写、字符空间小         | 一般                    |
| `River9!Maple`        | 长度较长且大小写、数字、符号混合  | 较强                    |
| `Tr0ub4dor&3`         | 长度 11、字符类型齐全      | 较强                    |
| `T7!qL2#vN8@pR4$z`    | 长度充足、字符类型丰富、无明显模式 | 很强                    |

## 9. 边界与维护

- 评分是启发式指标，不等价于泄露库查询、破解时间估算或安全证明；不要把等级文案写成「绝对安全」。
- 词表与键盘序列保持小型。新增模式时应补充示例并检查误报，同时更新第 8 节。
- 修改长度分档、加减分值或等级阈值后，需同步更新本文档和人工验收场景。
- 生成器界面参数范围（长度 8–20、最少数字与符号 0–8）由 `GeneratorComponents.ets` 控制，改动界面范围不会改变引擎的 8–128 限制。
